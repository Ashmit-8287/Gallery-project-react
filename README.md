# React Image Gallery

A responsive image gallery application built using React, Axios, and Tailwind CSS. The application fetches images dynamically from the Picsum API and displays them in a clean card-based layout with pagination support.

## Features

* Dynamic image fetching using Axios
* Pagination (Next & Previous buttons)
* Responsive card layout
* React Hooks (useState, useEffect)
* Modern UI with Tailwind CSS
* External image links support

## Technologies Used

* React.js
* Axios
* Tailwind CSS
* Picsum API
* JavaScript (ES6+)

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/gallery-project.git
```

Navigate to the project folder:

```bash
cd gallery-project
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
